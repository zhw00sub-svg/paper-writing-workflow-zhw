# Skill Registry

## Core Skills

| Skill | Function |
|---|---|
| `scientific-writing` | academic prose, structure, and manuscript drafting |
| `literature-review` | systematic evidence gathering and synthesis |
| `research-lookup` | targeted research lookup and evidence completion |
| `citation-management` | DOI, BibTeX, and citation metadata validation |
| `scientific-critical-thinking` | claim testing, evidence strength, and reasoning control |
| `peer-review` | reviewer-style critique and risk detection |
| `venue-templates` | journal or venue-specific formatting guidance |
| `seaborn` | draft statistical plotting and exploratory visuals |
| `spreadsheet` | structured data tables and plotting handoff sheets |

## Clinical and Statistical Skills

| Skill | Function |
|---|---|
| `clinical-reports` | clinical framing, endpoint wording, and medical context |
| `statistical-analysis` | test selection, reporting logic, and analysis planning |
| `statsmodels` | regression and formal model implementation |
| `scikit-survival` | survival analysis workflows |

## Figure Policy

Figures are first-class scientific artifacts. The workflow requires:

- draft visuals before final visual handoff
- figure-ready data for human final plotting in SPSS, R, or Prism
- captions, legends, and plotting guidance as standard outputs
